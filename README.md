# INVENT SUN

A tiny web game about inventing suns. You are at the cosmic invention
workshop: a dormant star egg waits in the dark while you assemble it from
invention components — Stellar Core, Plasma, Magnetosphere, Stellar Flare,
Nova Shell, Fusion Heart. Every click adds a real layer to the star and feeds
the energy gauge. Spend energy until the gauge is full, then press IGNITE. The
star ignites, detonates, and you bank the score. Invent a few suns and the next
one starts measurably bigger.

## Step-by-step reasoning

1. **Scoping the loop.** A playable game needs exactly three verbs: add an
   invention, charge the star, ignite it. Everything else was cut after that.
2. **Stack choice.** Plain HTML/CSS/JS with the Canvas 2D API. The deliverable
   has zero build step, which is the only sane way to be served by GitHub Pages
   with no pipeline. The whole game lives in one file.
3. **Data-driven visuals.** The star is drawn from the current layer list, so
   each invention composes into a plausible glowing star rather than being
   cosmetic stickers.
4. **Juice.** Ignition is a particle burst with additive blending plus a flash;
   the score phase starts only when the last particle has died.
5. **Escalation.** Each invented star scales the next one's base size, so the
   failure mode of a small game — running out of ideas — never arrives.

## Play

Click inventions to fill the energy gauge, hit IGNITE, and bank the score. Invent
another sun.
